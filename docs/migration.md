# KSwitcher Files migration

The baseline is [KSwitcher Files v0.6.119](https://gitea.hrynco.com/hrynco/hrynco-kswitcher/src/tag/v0.6.119/FILES-UI.md). Dirlume carries over file-manager behavior and settings while using the Revqora approach to desktop layout and controls.

| Area | Available in Dirlume | Remaining for parity |
| --- | --- | --- |
| Panes and sources | Independent history, path navigation and folder completion for local and FTP panes, pinned parent-folder rows, numbered bookmark groups for local and KSwitcher folders, local and remote sources, swap, sorting, filtering, quick prefix search, recursive filename search and a virtual results panel, hiding, keyboard and mouse multi-selection, pane resizing, saved column widths and visibility, automatic folder refresh, local workspace restoration, FTP folder restoration in either pane, local and FTP folder sizes and marked-size summaries, free space on local drives, and the Classic commander layout | Brief and Wide views, capacity of remote sources, other providers’ remote folder size scans, and reopening authenticated Dirlume Server and KSwitcher sessions |
| File operations | Copy and move dialogs, editable destinations, progress and cancellation for local transfers and Dirlume server downloads, existing file and folder prompts, per-transfer conflict decisions, folder merging, same-volume and cross-volume moves, rename, local batch folder creation, directory links with dated name history, create files, Trash, permanent deletion, drag and drop, system file clipboard, file attribute inspection and writable local flags, Windows Shell context menus, Windows lock inspection and administrator launch | Remote file replacement, remote folder creation and links, append on copy, per-provider progress and cancellation for KSwitcher, resume, deletion progress, and native context menus, lock inspection, and elevation on macOS and Linux |
| Viewer and editor | UTF-8 and UTF-16 with BOM, encoding choice when creating text files, local save checks for external edits, text editing, local, FTP, and Dirlume server preview, FTP editing with revision checks, themed syntax highlighting, Markdown with Mermaid, active document and heading links, and an HTML formatting toggle for non-wrapping table text, task checkboxes saved to local and writable FTP files, paged read-only hex view, multiple document windows with keyboard cycling, local window restoration, and an unsaved-changes prompt | Paged text editing, Save As, find and history, changing the encoding and line endings of existing files, image preview, remote edits through other providers, and draft recovery after exit |
| Processes | Sortable system process table with CPU and memory in either pane, search by name or PID, Windows executable icons, confirmation before terminating selected processes, and Windows file lock detection with process selection | Lock inspection on macOS and Linux |
| File comparison | Native resizable comparison window, unified and side-by-side local, FTP, and Dirlume server text, line numbers, intraline highlighting, change navigation, aligned panes with a resizable divider and change connectors, collapsible unchanged sections, a whitespace toggle, editing and applying changes in either direction, and per-file save destinations | Comparison-specific colors, KSwitcher sources, and original file-size and line-count limits |
| Archives | 7-Zip command line integration for local creation and pane browsing, ZIP/7z/TAR and WIM when supported, preset profiles, AES and split volumes, normal copy conflicts for extraction, text editing and member deletion in writable archives | In-place changes to encrypted and split archives, transfers into archives, and an integrated compression engine |
| Terminal | Interactive PowerShell or system shell accessible beside the command line, panel-to-shell directory synchronization in supported shells, shared, dated history of command-line and interactive PowerShell, Bash and Zsh submissions, topic search, command recall, shell-aware completion in the command line, file and path insertion, local command execution from the active pane, contextual F1 help, and a keyboard shortcut to hide and restore panels | Shell-to-pane directory synchronization, opening BAT/CMD in the live terminal, and remote sessions |
| FTP | Saved profiles with system credential storage, UTF-8 and legacy code pages, initial directory and parent navigation, file viewing and editing, recursive measurement and search, bidirectional local/FTP copy with progress and conflicts, rename, and deletion confirmation | Live verification on macOS and Ubuntu. The connection chooser opens as a dialog. |
| KSwitcher LAN | Paired computers, drives, browsing, and file downloads through the Windows Dirlume Bridge | Bidirectional and resumable transfers, remote edits, rename, Trash, folder creation, Wake-on-LAN, hibernate, terminal, and remote update under KSwitcher's permissions |
| Dirlume server | A separate TLS process with invitation-based access. Clients can browse a share and download files and directory trees. | Access management for multiple shares, write operations, bidirectional transfers, resume, service installers, and GUI administration |
| Appearance and shortcuts | Resizable Options with searchable settings tree, interactive color picker and draft previews, saved custom palettes for the window, panels, dialogs, text tools, and file type categories, separate colors for hidden, system and marked entries, Standard, Twin panels and Classic commander panel layouts with drive buttons, a volume line and a current-item status line, system fonts per area, cached Windows Shell icons, button tooltips, and configurable bindings with conflict checks and reset | Custom rules for individual extensions, native icons on macOS and Linux, an OS-level launch shortcut, and bindings for the remaining features |
