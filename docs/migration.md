# KSwitcher Files migration

The baseline is [KSwitcher Files v0.6.119](https://gitea.hrynco.com/hrynco/hrynco-kswitcher/src/tag/v0.6.119/FILES-UI.md). Dirlume carries over file-manager behavior and settings while using the Revqora approach to desktop layout and controls.

| Area | Available in Dirlume | Remaining for parity |
| --- | --- | --- |
| Panes and sources | Independent history, path navigation, local and remote sources, swap, sorting, filtering, hiding, keyboard and mouse multi-selection, resize, automatic local refresh, local folder sizes and marked-size summaries | Brief and Wide views, numbered bookmarks and groups, prefix search, drive capacity, and remote folder size scans |
| File operations | Copy and move dialogs, editable destinations, progress and cancellation for local copying and Dirlume server downloads, local file conflict prompts, same-volume moves, rename, create files and folders, Trash, and permanent deletion | Folder merging and remote file replacement, cross-volume moves, links, per-provider progress and cancellation for KSwitcher, resume, batch folder creation, deletion progress, locked files, and elevation where supported |
| Viewer and editor | UTF-8 and UTF-16 with BOM, local save checks for external edits, create and edit text files, text and Markdown preview from local and Dirlume server panes, and an unsaved-changes prompt | Paged editing for large files, Save As, find and history, syntax highlighting, selectable encoding and line endings, separate windows and profiles, image preview, full Markdown with Mermaid, links and editable checkboxes, and remote edits |
| File comparison | Side-by-side local and Dirlume server text, change groups and navigation, and an option to show whitespace changes | Line numbers, intraline highlighting, zoom and resizable columns, comparison-specific colors, KSwitcher and FTP sources, and original file-size and line-count limits |
| Terminal | Embedded shell, persistent command-line history and recall, file and path insertion, local command execution from the active pane, and a keyboard shortcut to hide and restore panels | Completion in the command line, shell-to-pane directory synchronization, opening BAT/CMD in the live terminal, contextual F1 help, and remote sessions |
| FTP | Pending | Saved connections and protected credentials, UTF-8 and legacy encodings, view and edit, copy in both directions, rename, and delete |
| KSwitcher LAN | Paired computers, drives, browsing, and file downloads through the Windows Dirlume Bridge | Bidirectional and resumable transfers, remote edits, rename, Trash, folder creation, Wake-on-LAN, hibernate, terminal, and remote update under KSwitcher's permissions |
| Dirlume server | A separate TLS process with invitation-based access. Clients can browse a share and download files and directory trees. | Access management for multiple shares, write operations, bidirectional transfers, resume, service installers, and GUI administration |
| Appearance and shortcuts | Saved custom palettes for the window, panels, dialogs and text tools, independent fonts, contextual KSwitcher Files defaults for migrated commands, and configurable bindings with conflict checks and reset | Per-file-type styles, an OS-level launch shortcut, and bindings for the remaining features |
