# KSwitcher Files migration

The baseline is [KSwitcher Files v0.6.119](https://gitea.hrynco.com/hrynco/hrynco-kswitcher/src/tag/v0.6.119/FILES-UI.md). Dirlume carries over file-manager behavior and settings while using the Revqora approach to desktop layout and controls.

| Area | Available in Dirlume | Remaining for parity |
| --- | --- | --- |
| Panes and sources | Independent back and forward history, address navigation, parent folder, local drives, active pane, swap, sorting, filtering, hidden items, marks, automatic local refresh, cancellable local folder sizes, and marked-size summaries | Brief and Wide views, pane sizing and visibility, numbered bookmarks and groups, prefix search, drive capacity, and remote folder size scans |
| File operations | Open with the OS, staged file and tree copy without overwrites, same-volume moves, rename, create a folder, and send items to Trash | Links, cross-volume moves, transfer destination and conflict options, progress and cancellation, resume, batch folder creation, permanent deletion and progress, locked files, and elevation where the platform supports it |
| Viewer and editor | Local UTF-8 and UTF-16 with BOM, save checks for external edits, Markdown preview, and an unsaved-changes prompt | Paged editing for large files, new text files and Save As, find and history, syntax highlighting, selectable encoding and line endings, separate windows and profiles, image preview, full Markdown with Mermaid, links and editable checkboxes, and remote read/write |
| File comparison | Side-by-side local text, change groups and navigation, and an option to show whitespace changes | Line numbers, intraline highlighting, zoom and resizable columns, comparison-specific colors, remote sources, and original file-size and line-count limits |
| Terminal | An interactive shell starts in the active local folder. PowerShell runs on Windows, and the user's shell runs on macOS and Ubuntu. History and completion use the shell's facilities. | Dirlume command history, file and path insertion, active-folder synchronization with a running shell, launch BAT/CMD files in the terminal, and remote sessions |
| FTP | Pending | Saved connections and protected credentials, UTF-8 and legacy encodings, view and edit, copy in both directions, rename, and delete |
| KSwitcher LAN | Paired computers, drives, browsing, and file downloads through the Windows Dirlume Bridge | Bidirectional and resumable transfers, remote edits, rename, Trash, folder creation, Wake-on-LAN, hibernate, terminal, and remote update under KSwitcher's permissions |
| Dirlume server | A separate TLS process with invitation-based access. Clients can browse a share and download files. | Access management for multiple shares, write operations, bidirectional and recursive transfers, resume, service installers, and GUI administration |
| Appearance and shortcuts | Application-wide color schemes, configurable command shortcuts, conflict checks, and reset | Custom palettes, fonts, per-file-type styles, an OS-level launch shortcut, and configurable bindings as new commands are added |
